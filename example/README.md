# Toastification example

**[Launch the web preview](https://swanflutter.github.io/toastification/)**

This interactive Flutter app previews all built-in toast styles, including the conversational `chat` layout. Use the controls to switch between light and dark themes, adjust toast content and colors, and preview left-to-right or right-to-left layouts.

## Run locally

```shell
flutter pub get
flutter run -d chrome
```

For desktop builds, use a supported Flutter desktop toolchain:

```shell
flutter run -d windows
flutter run -d linux
flutter run -d macos
```

Android, iOS, Linux, macOS, Windows, and Web builds are checked by the repository's GitHub Actions workflows.
